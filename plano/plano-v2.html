Como isso vira código

Movimento

  • A página tem altura “falsa” e o scroll vertical é convertido em deslocamento horizontal (GSAP ScrollTrigger). Assim roda do mouse, trackpad, barra de rolagem e teclado funcionam sem truque.
  • Câmera segue o personagem com leve atraso. O céu e a cidade andam mais devagar (parallax em 3 camadas).
  • Personagem anda enquanto há movimento, para quando o scroll para e vira de lado quando a pessoa volta.
  • Entrada em CSS 3D + Motion: abre instantâneo, sem carregar modelo 3D.
  • Reduced-motion: a intro vira um fade e a fase vira trilha com cortes secos.

Base

  • Vite + React + TypeScript.
  • Tailwind v4 + shadcn/ui pra receber componentes do 21st.dev e do Origin UI com npx shadcn add <url>.
  • A paleta escolhida vira tokens CSS, então qualquer componente instalado já nasce rosa ou verde.
  • Zonas e projetos descritos num arquivo de dados: adicionar um projeto = mais um gabinete no corredor.
  • Deploy na Vercel.
